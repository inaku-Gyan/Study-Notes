\section{Markov Chains}

\subsection{Definitions}

\paragraph*{Stochastic Process}
A stochastic process is a family of random variables
\( \big \{ X(t) \colon t \in T \big \} \)
defined on a \emph{probability space},
where \(T\) is the \emph{parameter set}.
When \( T = \big \{ 0, 1, 2, 3, \ldots \big \} \),
it is usually referred to as a time series.
When \(T\) is a vector space, the stochastic process is called a random field.
The collection of all possible states (values) of \(X(t)\) forms the
\emph{state space}, which can be either discrete or continuous.

\paragraph*{Markov Assumption / Markov Property; Markov Process / Markov Chain}
A Markov process (or Markov chain) is a stochastic process indexed by time,
which satisfies the Markov assumption (or Markov property)
--- namely, the \emph{conditional probability distribution}
of the current state depends on only a
\emph{finite fixed number} of previous states, i.e.,
\begin{equation*}
  P(\textcolor{red}{X_t} \mid \big \{
  X_{t-1}, X_{t-2}, \ldots \big \} )
  = P(\textcolor{red}{X_t} \mid \big \{
  X_{t-1}, X_{t-2}, \ldots, X_{t-k} \big \} )
  \qq{for any \(t\)}
\end{equation*}

\paragraph*{First-Order Markov Process}
A first-order Markov process is a Markov process where
the current state depends only on the immediately preceding state, i.e.,
\begin{equation*}
  P(\textcolor{red}{X_t} \mid \big \{
  \textcolor{blue}{X_{t-1}}, X_{t-2}, \ldots \big \} )
  = P(\textcolor{red}{X_t} \mid \textcolor{blue}{X_{t-1}})
  \qq{for any \(t\)}
\end{equation*}
In the following sections, we will focus on first-order Markov processes.
Without specification, a Markov process is assumed to be first-order.

From above, we can see that Markov processes
are a special class of \emph{Bayesian networks}.
And the transition model is
the \emph{conditional probability table} (CPT) of
the first-order Markov process.
Compared to a general Bayesian network,
a first-order Markov process has a simpler structure (a chain)
and fewer parameters (only one CPT).

\subsection{Markov Chain Inference}

Inference on Markov chains is basically the same as
inference in Bayesian networks.

\paragraph*{Forward Algorithm}
Forward algorithm is a dynamic programming algorithm
used to solve queries about
the current state given a previous state.
It is simply based on the following equation:
\begin{equation*}
  \newcommand{\x}{\textcolor{blue}{x}}
  P(X_t) =
  \sum_{\x \, \in \, S }
  P(X_t \mid X_{t-1} = \x) P(X_{t-1} = \x)
  \qquad\qq{where}
  S = \{ \text{all possible states} \}
\end{equation*}

\subparagraph*{Matrix representation}

The forward algorithm can be expressed in matrix form.
Suppose the set of all possible states is given by
\(S = \{ s_1, s_2, \ldots, s_n \} \).
Then we can represent the transition model
as an \(n \times n\) matrix \(\bm{M}\),
where the entry \(\bm{M}[i,j] := P(X_t = s_i \mid X_{t-1} = s_j)\).
Let the vector \(\bm{p}_t\) represent
the probability distribution of \(X_t\),
i.e., \(\bm{p}_t[i] := P(X_t = s_i)\).
Then the forward algorithm can be expressed as
\begin{equation*}
  \bm{p}_t = \bm{M} \bm{p}_{t-1}
  \qq{i.e.}
  \begin{bmatrix}
    P(X_t = s_1) \\
    \vdots \\
    P(X_t = s_n)
  \end{bmatrix}
  =
  \begin{bmatrix}
    P(X_t = s_1 \mid X_{t-1} = s_1)
    & \cdots & P(X_t = s_1 \mid X_{t-1} = s_n) \\
    \vdots & \ddots & \vdots \\
    P(X_t = s_n \mid X_{t-1} = s_1)
    & \cdots & P(X_t = s_n \mid X_{t-1} = s_n)
  \end{bmatrix}
  \begin{bmatrix}
    P(X_{t-1} = s_1) \\
    \vdots \\
    P(X_{t-1} = s_n)
  \end{bmatrix}
\end{equation*}

\section{Hidden Markov Model (HMM)}

\subsection{Definitions}

When the obseved variables are not the states of the Markov process,
but are generated by the states, we have a hidden Markov model (HMM).

\paragraph*{Sensor Markov Assumption}
To make it easier,
we assume that the current observation depends
only on the current state, i.e.,
\begin{equation*}
  P(\textcolor{red}{E_t} \mid \big \{
      \textcolor{blue}{X_t}, X_{t-1}, X_{t-2},
  \ldots, E_{t-1}, E_{t-2}, \ldots \big \})
  = P(\textcolor{red}{E_t} \mid \textcolor{blue}{X_t})
  \qq{for any \(t\)}
\end{equation*}

\paragraph*{Transition Model \& Sensor Model}
In an HMM, we have two models
(two CPTs in the corresponding Bayesian network):
\begin{itemize}
  \item Transition model (same as in Markov processes):
    \(P(X_t \mid X_{t-1})\)
  \item Sensor model (or observation model): \(P(E_t \mid X_t)\)
\end{itemize}

\subsection{Inference}

There are four basic inference tasks in a temporal model:
\begin{itemize}
  \item \textbf{Filtering}:
    Finding the current state given all evidence up to now, i.e.,
    computing
    \begin{equation*}
      P(X_t \mid E_1 = e_1, E_2 = e_2, \ldots, E_t = e_t)
      \qquad\qq{or simply}
      P(X_t \mid \bm{e}_{1:t})
    \end{equation*}
  \item \textbf{Prediction}:
    Finding the future state given all evidence up to now, i.e.,
    computing
    \begin{equation*}
      P(X_{t+k} \mid \bm{e}_{1:t})
      \qq{for some \(k > 0\)}
    \end{equation*}
  \item \textbf{Smoothing}:
    Finding the past state given all evidence up to now, i.e.,
    computing
    \begin{equation*}
      P(X_{k} \mid \bm{e}_{1:t})
      \qq{for some \(0 < k < t\)}
    \end{equation*}
  \item \textbf{Most likely explanation}:
    Finding the most likely sequence of states given all evidence up
    to now, i.e.,
    \begin{equation*}
      \arg\max_{\bm{x}_{1:t}}
      P(\bm{X}_{1:t} = \bm{x}_{1:t} \mid \bm{e}_{1:t})
    \end{equation*}
\end{itemize}

In addition to the above inference tasks,
we also have \textbf{learning}:
The transition and sensor models, if not yet known,
can be learned from observations.

\subsubsection{Filtering and Prediction}

Let \( \alpha \) be the normalization constant that
dose not depend on \(x_t\).
\begin{align*}
  P(X_t = x_t \mid \bm{e}_{1:t})
  &= \alpha \cdot P(X_t = x_t, \bm{e}_{1:t-1}, e_t) \\
  &= \alpha \cdot P(e_t \mid X_t = x_t, \bm{e}_{1:t-1})
  \cdot P(X_t = x_t, \bm{e}_{1:t-1})
  \qquad\text{by Bayes' Theorem} \\
  &= \alpha \cdot P(e_t \mid X_t = x_t)
  \cdot P(X_t = x_t, \bm{e}_{1:t-1})
  \qquad\text{by sensor Markov assumption}
  \intertext{
    Note that the term \(P(X_t = x_t, \bm{e}_{1:t-1})\)
    represents a one-step prediction.
  }
  &= \alpha \cdot P(e_t \mid X_t = x_t)
  \cdot \sum_{x_{t-1}} P(X_t = x_t, X_{t-1} = x_{t-1}, \bm{e}_{1:t-1}) \\
  &= \alpha \cdot P(e_t \mid X_t = x_t)
  \cdot \sum_{x_{t-1}} P(X_t = x_t \mid X_{t-1} = x_{t-1}, \bm{e}_{1:t-1})
  P(X_{t-1} = x_{t-1}, \bm{e}_{1:t-1}) \\
  &= \alpha \cdot P(e_t \mid X_t = x_t)
  \cdot \sum_{x_{t-1}} P(X_t = x_t \mid X_{t-1} = x_{t-1})
  P(X_{t-1} = x_{t-1}, \bm{e}_{1:t-1})
  \qquad\text{by Markov assumption}
\end{align*}
In the above result,
the three probability terms on the right-hand side are given by
the sensor model, the transition model, and the previous filtering result,
respectively.
Thus, filtering and prediction can be solved by iterating the above equation.

\part*{Probabilistic Reasoning Over Time}

\section{Markov Chains}

\paragraph*{Stochastic Process}
A stochastic process is a family of random variables
\( \big \{ X(t) \colon t \in T \big \} \)
defined on a \emph{probability space},
where \(T\) is the \emph{parameter set}.
When \( T = \big \{ 0, 1, 2, 3, \ldots \big \} \),
it is usually referred to as a time series.
When \(T\) is a vector space, the stochastic process is called a random field.
The collection of all possible states (values) of \(X(t)\) forms the
\emph{state space}, which can be either discrete or continuous.

\paragraph*{Markov Assumption / Markov Property; Markov Process / Markov Chain}
A Markov process (or Markov chain) is a stochastic process indexed by time,
which satisfies the Markov assumption (or Markov property)
--- namely, the \emph{conditional probability distribution}
of the current state depends on only a
\emph{finite fixed number} of previous states, i.e.,
\begin{equation*}
  P(X_t \mid \big \{ X_{t-1}, X_{t-2}, \ldots \big \} )
  = P(X_t \mid \big \{ X_{t-1}, X_{t-2}, \ldots, X_{t-k} \big \} )
  \qq{for any \(t\)}
\end{equation*}

\paragraph*{First-Order Markov Process}
A first-order Markov process is a Markov process where
the current state depends only on the immediately preceding state, i.e.,
\begin{equation*}
  P(X_t \mid \big \{ X_{t-1}, X_{t-2}, \ldots \big \} )
  = P(X_t \mid X_{t-1})
  \qq{for any \(t\)}
\end{equation*}
In the following sections, we will focus on first-order Markov processes.
